# TinCanArgentum 라이선스 안내

이 문서는 저장소 루트의 `LICENSE`가 적용되는 범위와 제3자 자료의
취급을 설명합니다.

## 프로젝트 코드

TinCanArgentum 기여자가 저작권을 보유한 원본 소스 코드와 문서는
`LICENSE`의 MIT License로 배포합니다. 여기에는 원칙적으로 다음 경로의
원본 코드가 포함됩니다.

- `main.py`
- `cogs/`
- `fcts/`
- `games/`
- `scripts/`
- 프로젝트 기여자가 직접 작성한 설정 및 번역 문서(API 생성물과 제3자
  자료는 제외)

파일 안에 별도의 저작권 또는 라이선스 고지가 있으면 그 고지가 우선합니다.

## MIT License가 적용되지 않는 항목

다음 항목은 프로젝트의 MIT License에 자동으로 포함되지 않습니다.

- `font/`의 글꼴 파일
- `config/` 및 `data/`의 이미지, 데이터베이스, 스프레드시트와 데이터셋
- 소스 코드가 연결하는 외부 API 및 그 응답 데이터
- `requirements-*.txt`로 설치되는 Python 패키지
- 소스 코드에 URL로 연결된 외부 이미지, 음원, 영상 및 기타 콘텐츠
- 상표, 서비스명, 캐릭터, 게임 데이터 등 제3자의 지식재산

각 항목에는 저작권자가 정한 별도의 라이선스나 서비스 약관이 적용됩니다.
자세한 내용은 `THIRD_PARTY_NOTICES.md`, `ASSET_LICENSES.md`,
`font/LICENSES/README.md`를 확인하십시오.

현재 저장소에는 라이선스 또는 재배포 허가를 확인할 수 없는 글꼴과 미디어
파일이 포함되어 있습니다. 이 파일들은 권리 확인 전까지 공개 릴리스,
설치 프로그램, 컨테이너 이미지 또는 실행 파일에 포함하지 않는 것이
안전합니다. 단순히 이 저장소에 라이선스 문서를 추가하는 것으로 제3자
파일의 이용 권한이 새로 생기지는 않습니다.

이 문서는 법률 자문이 아닙니다. 상업 배포 또는 대규모 공개 배포 전에는
각 권리자의 최신 조건을 다시 확인하십시오.
